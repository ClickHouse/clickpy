Monthly Insights Report

PyPI Usage — August 2026

A developer-focused look at global Python package download activity, based on the public PyPI download-stats dataset (ClickPy).

In August 2026, PyPI recorded roughly 176.6 billion package downloads across ~869,000 distinct projects — a ~4.5% dip from July 2026's 185.0 billion downloads. The overall package mix stayed remarkably stable month-over-month: the same handful of foundational libraries (AWS SDKs, packaging/build tooling, the core HTTP stack) anchor the top of the charts, while a smaller set of fast-growing, AI-agent- and cloud-tooling-related packages posted standout growth.

🔎 Takeaways

  • The US is overwhelmingly dominant (~78% of tracked downloads) and essentially flat month-over-month — consistent with the concentration of CI infrastructure (GitHub Actions, AWS us-east-1, etc.) rather than a statement about where Python developers live.
  • Singapore, Ireland, and the Netherlands rank unusually high for their population size — a strong signal that these figures track major cloud-region datacenters (AWS ap-southeast-1, AWS/GCP/Azure eu-west-1, eu-west-4) rather than local developer communities.
  • Notable shift — broad pullback: Singapore (-18.3%), Ireland (-16.4%), India (-19.4%), UK (-10.8%), South Korea (-10.7%), Belgium (-13.1%), Italy (-16.9%), and Poland (-12.9%) all declined more than the ~4.5% global average — plausibly tied to a European "summer slowdown," though this is an interpretation, not a confirmed cause.
  • Notable shift — growth against the trend: Switzerland (+27.7%), Russia (+12.5%), China (+5.9%), and Indonesia (+5.4%) all grew despite the global decline.
  • New entrant / dropout: Mexico entered the top 25 countries in August; Israel dropped out (was present in July).

🔎 Takeaways

  • The list is dominated by transitive dependencies of the AWS SDK and packaging/build toolchain (boto3, botocore, packaging, setuptools) and the core secure-HTTP stack (certifi, idna, urllib3, requests, charset-normalizer, cryptography, cffi) — nearly every Python environment, CI job, and container build resolves these regardless of the "primary" project.
  • boto3's total download volume fell ~14% month-over-month (3.72B in July → 3.21B in August), the largest swing among the top 10 — plausibly tied to the same broad seasonal dip seen in the geographic data, though it's worth flagging as an anomaly rather than a firm conclusion.
  • The Pydantic ecosystem is visibly gaining footprint: annotated-types and typing-inspection — both dependencies introduced by Pydantic v2 — climbed into the top 30 in August, having been just outside it in July, while grpcio-status and s3transfer slipped out.

mcp-types MCP ecosystem

44K → 61.3M downloads, June → August

Went from ~44K downloads in June to 61.3M in August, tracking real, incrementing semantic-version releases (2.0.0 → 2.1.0 → 2.1.1). The name and trajectory point to the fast-growing Model Context Protocol (MCP) ecosystem for connecting LLM-based agents to tools and data — one of the hottest areas of Python tooling in 2026.

openhands AI coding agents

46K → 137K → 188K → 1.1M → 2.5M, four consecutive months of >2x growth

A terminal-based CLI for the OpenHands AI coding agent. Downloads have more than doubled every month for four consecutive months — a textbook accelerating-adoption curve rather than a single spike.

google-cloud-parametermanager Cloud tooling

5.6x jump in August alone

The client library for Google Cloud's Parameter Manager service. Steady growth through July gave way to a 5.6x jump in August, suggesting a wave of new GCP customers or CI pipelines adopting the service.

bluetooth-data-tools IoT / Home Automation

~1.7–2x growth every month for four straight months

A low-level Bluetooth packet-parsing library used by Home Assistant's Bluetooth integrations. Its growth has been unusually smooth and compounding, suggesting organic adoption growth in the home-automation/IoT community rather than a one-off event.

metricflow Data engineering

~26x growth, April → August (despite a June dip)

dbt Labs' semantic-layer metrics engine. Despite a dip in June, it's up roughly 26x from April to August, consistent with growing interest in the dbt Semantic Layer among data engineering teams.

skia-python Graphics

24x jump in a single month (Jul → Aug)

Python bindings for Google's Skia 2D graphics engine. Essentially flat for three months, then a 24x jump in a single month — worth watching to see if this becomes a sustained trend or was driven by a single large consumer (e.g., a popular library newly adding it as a dependency).

🧐 Honorable mentions (weaker signal)

problog (a probabilistic logic-programming toolbox) jumped from ~8K to 1.9M downloads in two months, and expression (a functional-programming library) grew ~80x from June to August — but neither project has published a new release since 2023, so the surge is more likely explained by a popular downstream package newly pulling them in as a transitive dependency than by direct, organic adoption. We're flagging them rather than featuring them prominently until that's confirmed.

•Methodology & Limitations

  • Source: ClickHouse's public PyPI download-stats mirror (pypi.pypi_downloads_per_month, pypi.pypi_downloads_per_day_by_version_by_country, pypi.projects), which replicates the official PyPI BigQuery download dataset.
  • Freshness: Latest data present at query time was 2026-09-06; August 2026 is the last fully-complete calendar month.
  • Population: No bot/test/CI filtering was applied beyond what PyPI's own dataset does — the vast majority of "downloads" are automated pip install calls, not manual developer actions.
  • Geographic coverage: Limited to the top 300 packages by August volume (≈70% of total downloads) for query-cost reasons; a full, unfiltered global aggregation across ~869K projects was not scanned.
  • Package rankings were re-aggregated with explicit GROUP BY project to correct for an in-flight merge artifact in the underlying SummingMergeTree table.
Source: raw exploration of ClickHouse's public PyPI dataset (pypi.pypi_downloads_per_month, pypi.pypi_downloads_per_day_by_version_by_country, pypi.projects) · Freshness: data through 2026-09-06; report covers the complete August 2026 calendar month (with July 2026 for comparison) · Key filters: geographic analysis limited to top 300 packages by volume (~70% of total downloads); package rankings re-aggregated to correct summing-table merge artifacts · Confidence: medium-high for package rankings and totals, medium for country shares (proxy for CI/cloud infrastructure location, not developer location), medium for "emerging" package causal explanations (based on name/description inference, not verified via package maintainers).
