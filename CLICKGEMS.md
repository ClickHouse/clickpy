# ClickGems

ClickGems is a free RubyGems download analytics site, powered by ClickHouse.

**Site:** https://clickgems.clickhouse.com

This repository also hosts [ClickPy](https://clickpy.clickhouse.com) on `main`. ClickGems lives on the `clickgems` branch of the same Next.js app and queries the public RubyGems dataset.

See the [announcement](https://clickhouse.com/blog/announcing-clickgems).
